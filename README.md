# 🧬 Advanced Computer Science, Algorithms & Architecture Lab

Este repositório serve como um laboratório central focado nos pilares teóricos e práticos da Ciência da Computação. O espaço reúne implementações rigorosas de estruturas de dados clássicas, análise de eficiência assintótica de algoritmos, paradigmas de resolução de problemas complexos, além de modelagem de governança e arquitetura de software.

---

## 🏗️ Organização do Laboratório por Pilares Técnicos

Para facilitar a navegação pelo ecossistema de arquivos, os scripts e modelos foram categorizados abaixo por suas respectivas especialidades científicas:

### 📊 1. Análise Assintótica & Performance (Complexidade de Algoritmos)
Scripts dedicados ao estudo matemático de eficiência de tempo e espaço de execução:
* `big_o.py` / `little_o.py`: Análise do pior cenário e limites superiores de execução de algoritmos.
* `theta.py` / `omega.py`: Modelagem do cenário médio (limite restrito) e melhor cenário de performance.
* `analise_assintotica_de_limites_de_complexidade.py` / `medidas_de_complexidade.py`: Estudo de limites matemáticos.
* `medidas_empiricas_de_performance.py`: Testes práticos e benchmarking de tempo de execução versus análise teórica.
* `relacao_de_recorrencia_para_analise_de_algoritmio_iterativos.py` / `..._recursivos.py`: Resolução de equações matemáticas para determinar a complexidade de loops e chamadas recursivas.

### 🧮 2. Paradigmas de Algoritmos & Otimização Combinatória
Implementações de diferentes estratégias de engenharia de software para resolução de problemas complexos:
* `algoritmo_guloso.py` (Greedy Algorithms): Escolhas locais ótimas na busca de uma solução global satisfatória.
* `heuristica.py` / `pesquisa_exaustiva.py` / `forca_bruta.py`: Algoritmos de busca e aproximação para problemas de alta complexidade computacional (NP-difíceis).
* `dividir_e_conquistar.py` (Divide and Conquer): Quebra de problemas em subproblemas menores (ex: MergeSort/QuickSort).
* `backtraccking.py` / `recursividade.py`: Algoritmos de exploração sistemática de caminhos e estruturas recursivas estruturadas.

### 🧱 3. Estruturas de Dados Clássicas
Modelagem e manipulação de dados em memória de forma eficiente:
* `arvores_binarias.py` / `arvores_de_busca.py` / `arvores_balanceadas.py`: Estruturas de árvores (como AVL ou Red-Black) focadas em busca rápida e ordenação.
* `tabelas_hash.py`: Implementação de estruturas de mapeamento chave-valor com tratamento de colisões para busca em tempo constante $O(1)$.
* `lista_encadeada_py` / `lista_ordenada.py`: Gerenciamento dinâmico de nós em memória.
* `pilhas.py` / `filas.py`: Estruturas de dados lineares baseadas nos padrões LIFO (Last-In, First-Out) e FIFO (First-In, First-Out).

### 🛡️ 4. Engenharia de Software, Governança & IA
Aplicações práticas de padrões de projeto, gerenciamento de memória e modelagem de processos:
* `modelando-uma-rede-neural` / `Untitled.ipynb`: Laboratório focado nos fundamentos matemáticos e estruturais de redes neurais artificiais.
* `abstracao.py` / `modularidade.py`: Princípios de Clean Code e Orientação a Objetos aplicada.
* `command.py` (Design Pattern): Implementação do padrão comportamental Command para encapsular requisições como objetos.
* `garbage_collection.py`: Estudo e simulação de gerenciamento automático de memória e desalocação de objetos ociosos.
* `governanca.bpmn` / `auditoria.bpmn`: Modelos visuais em padrão BPMN (Business Process Model and Notation) para mapeamento, governança corporativa e auditoria de fluxos de processos de tecnologia.

## 🛠️ Stack Tecnológica

* **Linguagem Principal:** Python 3 (Scripts de algoritmos e laboratórios matemáticos).
* **Ecossistema Web & Tipagem:** TypeScript (`index.ts`, `tsconfig.json`, `package.json`).
* **Modelagem de Processos:** BPMN 2.0 (Arquivos de conformidade e auditoria).
* **Ambiente Isolado:** Virtualenv (`venv/`, `.gitignore`).

## 🎯 Impacto Estratégico deste Portfólio

Dominar os fundamentos contidos neste repositório separa desenvolvedores de código comuns de **Arquitetos de Software e Cientistas de Dados Líderes**, garantindo:
1. **Otimização de Custos de Infraestrutura:** Escrever códigos sabendo a diferença entre uma execução $O(N^2)$ e $O(N \log N)$ economiza milhares de dólares em processamento de nuvem em larga escala.
2. **Arquitetura de Modelos Robustos:** Compreender estruturas de dados e gerenciamento de memória (`garbage_collection`) permite criar pipelines de dados que não sofrem com vazamentos de memória (*memory leaks*) sob estresse de carga.
3. **Conformidade e Processos:** O uso de documentação BPMN prova a capacidade de desenhar sistemas que respeitam regras estritas de auditoria interna, compliance e governança corporativa.
